# specs/ — 产品知识库

按模块一个文件（如 `specs/<模块>.md`），记录被测产品**已确认**的业务知识：

- 业务规则、状态流转（哪些迁移合法 / 禁止）、字段约束（必填、长度、默认值、校验文案）
- 容易混淆的概念区分（两个同名字段其实是两件事）
- 每条注明**来源**：需求文档章节号 / 实测日期 / 用户裁决（GATE 0）

规则：

- 只写已确认的结论。拿不准的疑点留在 `decomp.md` 里等 GATE 0，不要先写进来。
- 没有需求文档（C 档）时，页面实测得到的行为经 GATE 0 确认后回写这里，下一次同模块任务直接复用。
- 发现之前写错了，直接改正并注明改正日期和依据，不保留错误版本。
- 只描述**当前**产品行为；旧版本行为不需要保留。
